# 完整体验说明

打开首页即可开始，无需连接钱包或填写服务密钥。首次进入先了解产品用途，再选择感兴趣的主题。界面沿用“Orbit / 引力”。

## 五分钟操作路径

1. 选择“链上身份”等兴趣，进入推荐内容。打开详情、收藏或标记有用；试试分类、搜索、下一页和“不感兴趣 → 撤销”。
2. 点击“写体验 → 从使用笔记开始”，带入一份可修改的笔记。选择应用、补充感受、选择交互记录并发布。
3. 在详情查看操作摘要，可更换关联记录、编辑体验；“我的体验”集中管理本人内容。刷新后仍可看到保存结果。
4. 进入“我的精选 → 创建精选页”，填写名称并选择应用；展开“加入收藏与阅读内容”选择文章，创建后直接运行预览。
5. 点击“清爽列表”等快捷样式，再“应用页面调整”。也可填写“深色卡片；标题：我的链上工具箱；简介：值得反复打开的应用和笔记”。
6. 切换历史版本并返回当前版本，查看源码、复制HTML或下载当前版。关闭并刷新，再从“我的精选”打开。
7. 从账户入口修改昵称与兴趣；手机端可通过导航菜单进入个人操作和发布入口。需要重新了解用途时点击“新手引导”。

## 内容与保存

内置12篇使用内容、3篇官方资料笔记和6条交互记录，供笔试展示产品路径。每个浏览器会话有独立社区身份；收藏、反馈、发布、偏好和精选均经Go后端实际写入数据库。固定内容不能编辑，自己的体验可修改或软删除。

“交互记录”表示站内摘要关联，不是主网交易核验；记录不带交易哈希。默认不请求资产或签名操作。三个应用的官方链接仍会打开相应外部网站，外部网站不属于本站流程。

页面调整支持配色、版式、标题和简介；不支持的要求会提示可用写法，不保存空版本。全部操作仍遵守所有权、幂等和版本冲突检查。

## 本地运行

按README安装、构建、首次应用迁移并启动即可。`USEDIT_EXPERIENCE_MODE`默认开启，无需额外配置。原生API和Worker本地预览各自使用独立数据库；不应通过清空数据库来重复初始化。
