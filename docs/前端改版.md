# UsedIt 前端改版

## 本次变化

- 深石墨底色、银色实体材质、单一荧光绿强调，采用无衬线字体。
- 移除三栏资讯布局；首页由主视觉、应用快捷入口、分类与推荐卡片、个人精选入口组成。
- 保留应用目录、钱包登录、收藏、有用反馈、不感兴趣撤销、阅读偏好、体验编辑和精选页版本操作。
- 重做应用目录、个人精选、详情、表单、载入、空状态、错误提示与手机导航。
- 主视觉与个人精选配套素材已制作并随源代码交付。WebP 合计约 159 KiB，首屏图预加载，辅助图按需载入。
- 动效用于首屏内容进入、卡片反馈和弹窗切换；遵循减少动态效果设置。

## 实现边界

保持现有 React、TypeScript、Go 和数据协议。没有增加页面运行时依赖、后端调用或全局滚动事件。素材使用项目内静态文件，尺寸固定。

## 验证

- 类型检查、变更组件静态检查、方法和过程注释检查通过。
- 首次生产构建通过，浏览器直接运行生产 Worker 与本地 D1。
- 1280px 桌面：首页、应用筛选、应用目录、收藏切换与恢复、有用反馈切换与恢复、偏好弹窗、精选版本与页面预览均通过。
- 390px 手机：首页无横向溢出，导航与精选编辑器可用；主视觉与操作按钮均可见。
- 本次没有重测真实钱包扩展签名与主网交互；这些边界没有改动。
- 新建精选默认使用墨色网格，已保存页面保留自己的主题。
- 外置磁盘运行时首次加载较慢；临时复制同一二进制到本机工作目录并通过 cmp 校验后，预览正常。未修改安全设置。
