# Orbit · 引力 项目需求

更新：2026-10-25。根据本次笔试展示要求，默认使用内置内容与独立社区身份；此合同替代首版对外部钱包和服务配置的前置要求。需求先经 r0-request 结构化，再按 r0-work 实施。

## 产品目标

Web3 应用发现与体验社区，围绕“找应用 → 看体验 → 留下反馈 → 整理精选”形成 C 端使用闭环，体现 Go 后端、推荐与用户体验经验。延续深石墨、银色和浅绿视觉、两张品牌素材及首次使用引导。

## 核心范围

| 流程 | 可验收结果 |
| --- | --- |
| 首次使用 | 了解用途、选择兴趣或跳过；完成状态按浏览器记忆，可重新打开 |
| 发现内容 | ENS、Uniswap、OpenSea；12篇使用内容、3篇官方资料；搜索、分类、分页、推荐理由 |
| 互动 | 收藏、有用、不感兴趣和撤销；兴趣调整改变排序；刷新可恢复 |
| 发布管理 | 独立社区身份直接发文，可带入使用笔记；编辑、软删除，仅本人操作 |
| 记录关联 | 选择6条记录中属于当前应用的记录，保存摘要与时间；可更换记录，不标为主网核验 |
| 个人设置 | 修改昵称和兴趣，个人内容与精选由服务端隔离 |
| 精选页面 | 选择应用和内容；配色、版式、标题、简介；保存、运行预览、历史版本、复制与HTML导出 |
| 页面调整 | 三组快捷样式，以及“标题：…”、“简介：…”；本地执行并保存版本，不依赖密钥 |

## 技术与数据约束

- Go 承载领域逻辑，原生 HTTP + SQLite 与 Worker WebAssembly + D1 共用实现；React 负责交互。
- 固定内容库只读，个人操作实际入库。无预设互动热度，不创建钱包地址、签名或交易哈希。
- 写请求绑定服务端会话；发布幂等、修改 revision、精选 version、唯一互动和事务历史保持有效。
- 推荐候选最多200、每页12；批量读取互动，循环中不逐项访问数据库或链服务。
- 保留钱包签名与主网凭据路径，显式关闭 `USEDIT_EXPERIENCE_MODE` 才使用；默认无需钱包扩展、外部 RPC 或页面服务。
- 页面与文档遵守用户措辞要求。保持现有站点身份、所有者私有权限，不扩大分享范围。

## 不包含

游戏、资产交易、私钥托管、全链索引、自动操作外部DApp、任意应用代码构建、未经验证的推荐收益或容量结论。

## 失败处理

失败说明原因并保留输入；重复提交不新增记录，过期版本不覆盖新内容；无效记录或不支持的页面调整不冒充成功。历史页保留完整快照，预览隔离外部请求。

## 验收与交付

Go race/vet、TypeScript、生产构建；双用户隔离、持久化、幂等、冲突、分页、记录和精选版本集成测试；桌面与手机浏览器实际操作；原站发布后线上读取和写入复核。交付源码、运行说明、接口合同、架构取舍、操作路径和验收证据。
