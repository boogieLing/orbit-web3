# 首次使用引导

目标：首次打开即可理解 UsedIt 是一个 Web3 应用发现与体验社区，知道接下来能做什么。

## 使用路径

1. 首次进入自动展示欢迎页：找应用、看体验、收藏并整理精选。默认说明浏览、发布和整理均可直接使用；在钱包路径下再说明连接要求。
2. 点击「选兴趣，开始探索」，从应用已有标签中选择主题。通过现有偏好接口保存后，直接定位到推荐内容。
3. 任一步均可跳过；「跳过，先逛逛」和「暂不设置」进入应用目录，不写入兴趣。关闭弹窗留在当前页面。
4. 桌面左侧「引导」、首页「第一次来？从这里开始」、页脚「新手引导」及手机导航均可重新打开。

## 状态与边界

- 引导完成或主动跳过后，以浏览器本地标记记忆，下次访问不重复出现。新浏览器或清除站点数据后重新展示。
- 本地标记不包含身份、兴趣或内容。兴趣仍由服务端保存，并用于现有推荐排序。
- 本地存储受限时尝试会话存储；两者均不可用不阻止使用，但后续重新访问可能再次展示。
- 请求进行中锁定步骤和关闭操作，防止重复提交；失败保留兴趣并展示错误，可重试或暂不设置。
- 重开流程保留当前偏好；跳过不覆盖已有偏好。
- 首屏标题同时改为「发现值得用的 Web3 应用」，跳过引导后仍能看懂用途。
- 延续深石墨、银色和浅绿视觉，复用现有品牌素材。手机优先显示说明和操作。
