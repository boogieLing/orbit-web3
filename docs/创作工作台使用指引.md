# Orbit Studio 使用指引

入口：https://usedit-web3.ushouldknowr0.chatgpt.site/studio

1. 首次进入会说明“描述需求 → 运行试用 → 继续完善”。选择阅读收藏、DApp 收藏夹或社区报名示例，只会填入需求；点击“开始制作”才发起调用。
2. 先描述一个具体工具。制作时显示实际任务状态与已等待时间；完成后自动打开运行预览。
3. 在预览中添加内容、搜索和操作按钮。底部出现“应用数据已保存”后，可刷新确认。项目、完整对话与代码版本保存在当前访客身份下；使用同一浏览器回来继续。
4. 继续描述修改，例如“保留已有功能、数据和存储键，增加已读筛选”。可用 ⌘ / Ctrl + Enter 提交。未提交的需求草稿自动保留。
5. “版本历史”支持查看和恢复。历史预览为只读，返回当前版本或恢复后才能继续操作；代码恢复不主动回退应用数据。
6. “代码”查看当前产物，“导出 HTML”下载当前版本的独立网页文件。导出文件不包含工作台内已录入的业务数据。
7. 失败记录会保留；“取回需求，修改后再提交”将需求放回输入框，不自动重复调用。

## 适用范围

当前支持自包含的单页网页工具：内联样式和脚本、表单交互、工作台托管的键值数据。浏览器系统弹窗需改为页面内确认或撤销。页面不能访问外部网络或提交外部表单。需要外部服务、多文件构建或链上交易的应用不属于当前交付范围。
